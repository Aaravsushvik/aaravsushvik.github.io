Personal Portfolio Website

Built from scratch using semantic HTML, modern CSS custom properties, and approximately 300 lines of vanilla JavaScript.

The interactive canvas particle behavior adapts to device capabilities, connection conditions, screen width, and frame rate. It is disabled for reduced-motion preferences and Data Saver conditions and stops when the hero section is outside the viewport.

Accessibility features include a skip link, keyboard-friendly navigation, ARIA states, descriptive labels, live form status, 44px interaction targets, and strong color contrast.

The site also uses Schema.org JSON-LD, Open Graph metadata, canonical URLs, a sitemap, and a Content Security Policy.
